# 躲藏與密碼（hide-and-code）

第一人稱多人解謎遊戲：在昏暗的廢棄場景裡找出隱藏的**密碼條**，對應顏色的**密碼鎖**輸入後取得物品，再放到同色**放置點**即獲勝。怪物看見你 2 秒就會追，躲進衣櫃、床底、草叢可以擺脫。

- 3 張地圖：廢棄莊園（半森林・寬廣）、廢棄都市（高樓・空橋）、廢棄城堡（城牆・地牢）
- 房間制多人（最多 4 人，房主代碼加入，競速：最先完成配對者獲勝）；單人練習模式
- 電腦（鍵鼠）與手機（觸控）皆可，原生 WebGL 低多邊形畫面，無外部素材

## 遊玩
直接開啟 `index.html`（單人練習），或使用部署後的網址。多人需連網：房主「創建房間」取得 5 碼代碼，朋友「加入房間」輸入代碼即可。

| 操作 | 電腦 | 手機 |
|---|---|---|
| 移動 | WASD | 左側搖桿 |
| 視角 | 滑鼠 | 右側滑動 |
| 跑／蹲／跳 | Shift／Ctrl 或 C／空白鍵 | 跑、蹲、跳按鈕 |
| 互動 | E | 互動按鈕 |
| 手電筒／小地圖／聊天／選單 | F／M／Enter／Esc | 🔦／小地圖鈕／💬／☰ |

## 開發
```bash
node build.mjs          # 把 src/*.js 與 vendor/peerjs 內嵌成單一 index.html
node tools/test_maps.js # 地圖與導航網格檢查
node tools/test_sim.js  # 房主端規則／怪物 AI 單元測試
# 瀏覽器端對端測試（需要 Playwright）：
node tools/e2e_play.js  # 單人完整流程（MAP=0|1|2）
node tools/e2e_multi.js # 雙人房間／同步／搶先獲勝（BroadcastChannel 測試傳輸）
node tools/e2e_ui.js    # 設定、商店、暫停、躲藏、聊天、手機版面
```
多人連線使用 [PeerJS](https://peerjs.com)（MIT，已內嵌於 `vendor/`）：玩家之間以 WebRTC 點對點傳輸，僅用 PeerJS 公用媒合服務交換連線資訊。`?bc=1` 會改用同瀏覽器分頁的測試傳輸。

## 已知限制
- 全服排行榜、隨機配對陌生人、語音聊天、陷害隊友：尚未實作。個人最佳通關時間存在本機（LocalStorage）。
- 金幣、稱號只存在玩家本機，無法防作弊。
- 嚴格的企業／校園網路可能擋住 WebRTC 點對點連線（未設定 TURN 中繼）。
